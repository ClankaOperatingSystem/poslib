#+TITLE: poslib

Emacs library for a personal OS in Org files. Package: =pos=.

- =lisp/pos.el= :: lint, refile, dedupe, over the corpus; the root and
  its settings.
- =lisp/pos-sweep.el= :: the weekly sweep of done items into the archive
  each scope's configuration names: a plan, reviewed, then applied;
  and the sealing of a closed week.
- =lisp/pos-corpus.el= :: the corpus: every Org file a tree's
  configurations allow, each with the scope it belongs to, from one
  walk that every command reads.
- =lisp/pos-capture.el= :: capture to an intray.
- =lisp/pos-cid.el= :: IPFS CIDs of files and trees, computed locally.
- =lisp/pos-ledger.el= :: archive integrity ledgers, read and checked.
- =lisp/pos-links.el= :: the links in Org and Markdown files: found,
  resolved against the garden, and rewritten when what they point at
  is sealed.
- =lisp/pos-seal.el= :: sealing items into archives: a plan, reviewed, then applied.
- =lisp/pos-index.el= :: the CID index, ephemera, and Org's =ipfs:= links.
- =lisp/pos-migrate.el= :: a legacy archive brought under a ledger: the
  plan, reviewed, then applied.
- =lisp/pos-signin.el= :: signing in to a keeper that takes OAuth 2.0
  tokens, and the token kept, which pyposlib reads too.
- =lisp/pos-remote.el= :: the client's side of an archive kept away from
  its ledger, by a keeper reached at a URL.
- =lisp/pos-tree.el= :: a tree of repositories as its configurations declare it:
  the plan of what to clone, exclude and link, which changes nothing,
  and its application.
- =lisp/pos-startup.el= :: what a session opens with: prompts, then views
  of what is next, scheduled, due and to be reviewed, each item labelled
  by its scope.
- =lisp/pos-roam.el= :: the org-roam index of a tree, brought up to date
  before a command reads it: where the =id:= links to a heading are, for
  dedupe to point them at the copy it keeps. The user's own index serves
  where the tree lies in their =org-roam-directory=; elsewhere the tree
  has one of its own under the XDG cache directory.
- =doc/formats.org= :: the formats shared with [[https://github.com/ClankaOperatingSystem/pyposlib][pyposlib]], in lockstep.
- =doc/remote-archive-protocol.txt= :: what passes between a client and
  the keeper of a ledger's archive; =lisp/pos-remote.el= and pyposlib's
  =remote.py= are its clients, and any server that does what it says is
  a keeper.
- =doc/pos-directory.txt= :: what a node declares in =.clanka/= or =.pos/=: the
  repositories mounted beneath it, working trees, where archives are
  kept and the server it is bound to; how skills are linked through the
  tree; and the two steps of the tool that makes a tree as declared.
- =fixtures/= :: their examples, run by both.
- =test/= :: ERT tests, one file per module, on =test/pos-test-support.el=.

* Install

- Clone; load with =-L poslib/lisp=, with org-roam and what it requires
  on the load path, transient among them, newer than Emacs ships:
  =make deps= fetches them into =_deps/= at the commits the Makefile
  names.
- Or =package-vc=:

#+begin_src emacs-lisp
(package-vc-install
 '(pos :url "URL" :lisp-dir "lisp" :main-file "pos.el"))
#+end_src

- =:main-file= is relative to =:lisp-dir=.

* Configure

- Which files a command reads is declared in the tree's =.clanka/= or
  =.pos/= configurations, as =doc/pos-directory.txt= says: every Org
  file beneath the root but those under =exclude=, and those of a
  repository with no configuration.
- =pos-config.el= at the repository root; =pos-load-config= loads it.
  Sets =pos-refile-rules=, where a refile plan proposes a heading go,
  and =pos-prose-directories=, which the stranded-task scan leaves
  alone. A setting it once set and no longer reads is reported.
- Example: =test/pos-config.el=.

* Check

- =make check=: byte-compile (warnings are errors), checkdoc, tests.
- =make check-ipfs IPFS=path/to/ipfs=: the CID fixtures against kubo,
  offline, with the unixfs-v1-2025 profile.
