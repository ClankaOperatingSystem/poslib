#+TITLE: poslib

Emacs library for a personal OS in Org files. Package: =pos=.

- =lisp/pos.el= :: sweep, lint, refile, dedupe.
- =lisp/pos-capture.el= :: capture to an intray.
- =lisp/pos-cid.el= :: IPFS CIDs of files and trees, computed locally.
- =lisp/pos-ledger.el= :: archive integrity ledgers, read and checked.
- =lisp/pos-seal.el= :: sealing items into archives: a plan, reviewed, then applied.
- =lisp/pos-index.el= :: the CID index, ephemera, and Org's =ipfs:= links.
- =lisp/pos-remote.el= :: the client's side of an archive kept away from
  its ledger, by a keeper reached at a URL.
- =doc/formats.org= :: the formats shared with [[https://github.com/monkeypants/pyposlib][pyposlib]], in lockstep.
- =doc/remote-archive-protocol.txt= :: what passes between a client and
  the keeper of a ledger's archive; =lisp/pos-remote.el= and pyposlib's
  =remote.py= are its clients, and any server that does what it says is
  a keeper.
- =fixtures/= :: their examples, run by both.
- =test/= :: ERT tests.

* Install

- Clone; load with =-L poslib/lisp=.
- Or =package-vc=:

#+begin_src emacs-lisp
(package-vc-install
 '(pos :url "URL" :lisp-dir "lisp" :main-file "pos.el"))
#+end_src

- =:main-file= is relative to =:lisp-dir=.

* Configure

- =pos-config.el= at the repository root; =pos-load-config= loads it.
- Sets =pos-pillars=, =pos-prose-directories=, =pos-refile-rules=.
- Example: =test/pos-config.el=.

* Check

- =make check=: byte-compile (warnings are errors), checkdoc, tests.
- =make check-ipfs IPFS=path/to/ipfs=: the CID fixtures against kubo,
  offline, with the unixfs-v1-2025 profile.
